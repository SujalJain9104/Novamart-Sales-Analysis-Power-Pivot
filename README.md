# NovaMart Sales Analysis Dashboard

## Project Overview
An Excel-based business analytics project for analyzing NovaMart's sales transactions across products, customers, regions, and customer segments.

## Objective
- Analyze sales and quantity by product category
- Analyze customer segments, gender, and job location
- Compare regional sales performance
- Analyze product category performance across customer segments
- Identify marketing priorities based on the analysis

## Tools Used
- Microsoft Excel
- Power Pivot
- DAX
- PivotTables
- PivotCharts
- Slicers

## Dashboard Features
- Total Sales
- Total Quantity
- Category Analysis
- Customer Segment Analysis
- Regional Analysis
- Segment vs Category Analysis
- Interactive Slicers

## Key Insights
- Home Appliances is the strongest product category.
- Corporate is the strongest customer segment.
- Central is the strongest-performing region based on the analysis.
- Marketing priorities were identified using the combined analysis.
